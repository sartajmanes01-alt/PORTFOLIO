# Portfolio — Sartaj Singh

Personal portfolio website: data analyst & web developer. Static site — HTML, CSS and JavaScript, no build step.

## Live site
Once GitHub Pages is enabled: https://sartajmanes01-alt.github.io/portfolio/

## Files
- `index.html` — page structure
- `style.css` — styling (dark theme, plain black background)
- `data.js` — all content (about, skills, projects, certifications, experience)
- `script.js` — rendering, filters, typing effect, theme toggle
- `combineresume.pdf` — resume linked from the "Download CV" button

## Editing content
Change text, links and projects in `data.js` only — no HTML edits needed.
